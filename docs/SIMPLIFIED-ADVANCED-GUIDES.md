# Simplified Advanced Guides

The in-app **Simplified Advanced Guides** module uses one consistent learning ladder:

1. **One minute** — plain-language mental model.
2. **Actionable** — concrete steps a household, practitioner or project team can execute.
3. **Advanced** — system interactions, tradeoffs and data concerns.
4. **Expert / implementation** — architecture, governance, evaluation and failure modes.

Included v4 guides:

- Texas health collaboration operating model;
- Trystero 0.25.3 and WebRTC;
- Texas broadband + health-access status;
- mapping health-access challenges;
- multidisciplinary project design;
- WebLLM local planning architecture;
- PWA + offline architecture;
- evidence + provenance.

The HTML `<details>` pattern preserves progressive disclosure and keyboard accessibility. Search, expand-all and collapse-all controls operate on the bundled guide corpus.
